# Commit前チェックリスト

Commitボタンを押す直前に、30〜60秒で確認します。迷う項目が一つでもあれば、Commit・Pushを止めて、Changesと教材の該当Chapterを確認します。

## 7項目チェック

- [ ] **Current repository** は、今回作業するテスト用または対象のリポジトリです。
- [ ] **Current branch** は、この教材で使う `main` です。
- [ ] **Changes** には、今回のCommit対象だけが表示されています。
- [ ] **Summary** は、Changesに表示されるファイルの内容と一致しています。
- [ ] 個人情報、認証情報、意図しないファイルは含まれていません。
- [ ] 今回のCommitの目的を、一文で説明できます。
- [ ] Commit後にPushしてよい内容です。迷う場合は、Pushせずに確認します。

## 最後の確認

Commitはパソコン側の履歴へ記録する操作、PushはGitHubへ送る操作です。二つは別の操作であり、どちらも人間が差分を確認してから実行します。

このチェックリストは、正常フローを短く確認するためのものです。想定外のChanges、別リポジトリ、Push後のミスなどがある場合は、無理に進めずトラブル集または教材本文を確認します。
