# Chapter 5：ROADMAP.mdを作る

## この章の目的

プロジェクトの目的、最優先の成果物、現在のフェーズ、完了条件を一つの文書へまとめます。

## この章で行うこと

- ROADMAP.mdの役割を理解します。
- 最優先の成果物を一つに絞ります。
- 現在のフェーズと、今回の対象外を決めます。

ROADMAP.mdは、ルート直下ではなく `00_Command_Center/ROADMAP.md` に保存します。ファイル名だけでなく、保存場所も確認します。

## 手順

1. `ROADMAP_TEMPLATE.md`をコピーして使います。
2. プロジェクト名と目的を、自分の言葉で書きます。
3. 最初に完成させる成果物を一つだけ書きます。
4. 現在のフェーズと、このフェーズの完了条件を書きます。
5. 今回やらないことも書き、作業範囲を増やしすぎないようにします。
6. 分からない項目は、推測で埋めず「未決定」として残します。
7. Codexへ作成を頼む場合は、ROADMAP.md以外を変更しないよう範囲を伝えます。

## よくある間違い

- 最初から複数の商品や機能を最優先にする。最初の成果物を一つに絞ります。
- 収益や結果を保証する表現を使う。目標と保証は分けます。
- 未確認の市場情報を事実として書く。仮説や未確認を区別します。

## 完了条件

- [ ] プロジェクトの目的が書かれている。
- [ ] 最優先の成果物が一つに絞られている。
- [ ] 現在のフェーズと完了条件がある。
- [ ] 今回の対象外が分かる。
