# Chapter 2：環境を準備する

## この章の目的

安全な新規またはテスト用リポジトリを用意し、GitHub DesktopとCodexで作業を始められる状態にします。

## この章で行うこと

- GitHubアカウントとGitHub Desktopを準備します。
- 新規またはテスト用のリポジトリを用意します。
- 公開範囲と認証情報の扱いを確認します。

## 手順

1. GitHubアカウントへサインインします。
2. GitHub Desktopをインストールし、同じGitHubアカウントでサインインします。
3. 新規またはテスト用のリポジトリを作成します。本番の作業と混ぜない名前にします。
4. 公開範囲を確認します。教材用の画面を撮る予定がある場合は、Privateリポジトリを使う方法があります。
5. GitHub Desktopで対象リポジトリを開きます。
6. Codexでも同じローカルフォルダを開きます。
7. 次のChapterで、リポジトリ名・ブランチ・ローカルパスを確認します。

GitHub、GitHub Desktop、Codexの画面名や設定項目は更新で変わる場合があります。実際の画面表示を確認してください。

## よくある間違い

- 本番リポジトリとテスト用リポジトリを同じものとして扱う。名前と目的を分けます。
- APIキー、パスワード、アクセストークンをMarkdownへ書く。これらは保存しません。
- リポジトリを作っただけで、Codexが同じ場所を見ていると思う。次のChapterで確認します。

## 完了条件

- [ ] GitHub Desktopで対象リポジトリを開ける。
- [ ] Codexで対象のローカルフォルダを開ける。
- [ ] 本番用とテスト用を区別している。
- [ ] 個人情報・認証情報をファイルに書かないと確認した。
