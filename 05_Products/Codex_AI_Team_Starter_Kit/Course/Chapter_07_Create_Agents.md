# Chapter 7：AGENTS.mdを作る

## この章の目的

Codexが作業を始める前に読む、プロジェクト固有の作業ルールを用意します。

## この章で行うこと

- AGENTS.mdをルート直下へ置きます。
- Codexが読む順番と標準作業手順を決めます。
- Codexに一度に大量の作業を頼まないルールを置きます。

## 手順

1. `AGENTS_TEMPLATE.md`をコピーして使います。
2. プロジェクト名、目的、最優先の成果物を書きます。
3. 人間とCodexの役割を書きます。
4. Codexが読む順番として、AGENTS.md、ROADMAP.md、COMPANY_RULE.mdを指定します。
5. 作業前にGit状態を確認し、変更後に差分を確認すると書きます。
6. 外部公開、Push、課金、認証情報の利用は承認が必要と書きます。
7. ファイルをルート直下へ保存します。

## よくある間違い

- AGENTS.mdを`00_Command_Center`の中へ置く。最初に参照しやすいルート直下へ置きます。
- すべての作業を一度にCodexへ頼む。小さな目的へ分けます。
- 既存ファイルを読まずに上書きする指示になる。確認してから変更するルールを入れます。

## 完了条件

- [ ] AGENTS.mdがルート直下にある。
- [ ] ROADMAP.mdとCOMPANY_RULE.mdを読む順番がある。
- [ ] Codexの作業範囲と承認が必要な操作が分かる。
- [ ] 小さな単位で作業するルールがある。
