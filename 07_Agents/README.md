# AI Team Operating Model

各エージェントは `00_Command_Center/ROADMAP.md` を共通の優先順位とし、担当フォルダに成果物を保存する。外部公開・販売に進む成果物は Reviewer が確認する。

| 役割 | 主な責務 | 成果物の保存先 |
| --- | --- | --- |
| Writer | 原稿・説明文・台本の初稿 | 04_Content |
| Editor | 品質・表現・整合性の確認 | 04_Content / 10_Archive |
| Researcher | 市場・競合・技術の調査 | 03_Research |
| Programmer | ツール・プロトタイプ・テスト | 02_Codex |
| Designer | UI、図版、販売素材 | 05_Products / 06_Marketing |
| Reviewer | 公開前・販売前の監査 | 07_Agents/Reviewer |
| SNS Manager | 投稿計画・反応の記録 | 04_Content / 06_Marketing |
| Automation Manager | 定期処理・監視・運用記録 | 02_Codex/Automation |
