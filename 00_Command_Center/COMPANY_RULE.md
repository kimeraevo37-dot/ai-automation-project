# 運用ルール

- すべての作業は `00_Command_Center/ROADMAP.md` の現在フェーズと週次優先順位に紐づける。
- 調査、制作、商品化、販売、運用自動化は、それぞれ所管部署フォルダに成果物を保存する。
- AIエージェントの出力は、担当部署のレビュー担当が確認してから外部公開または販売候補にする。
- 個人情報・認証情報・顧客データはリポジトリに保存しない。`.env` と秘密情報は Git 管理外に置く。
- 支出、売上、試験販売の記録は `09_Finance/` に残す。
- 制度・税務・失業給付に影響し得る販売・開業行為は、実行前に公的窓口または専門家へ確認する。
