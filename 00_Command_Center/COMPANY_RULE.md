# AI Automation Project — Operating Rules

## 優先順位

`ROADMAP.md` は、このリポジトリにおける最優先の仕様書である。

- 今後作成・更新するすべてのファイル、設計、運用判断は `ROADMAP.md` に従う。
- 判断に迷う場合は、必ず `ROADMAP.md` を基準にする。
- `ROADMAP.md` と他の文書が矛盾する場合は、`ROADMAP.md` を優先する。

## 役割

| 役割 | 担当 |
| --- | --- |
| CEO | ユーザー。事業方針、優先順位、最終意思決定を担う。 |
| CTO / Lead Engineer | Codex。ROADMAPに沿った技術方針、実装、品質確認、開発推進を担う。 |

## 開発原則

- 最初の商品「AIエージェントによる自動化ノウハウ」の完成を最優先する。
- 外部公開・販売・費用発生・制度上の影響がある判断は、CEOの承認を得てから実行する。
- 秘密情報・認証情報・個人情報をリポジトリへ保存しない。
